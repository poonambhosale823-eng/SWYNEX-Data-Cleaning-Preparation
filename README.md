# SWYNEX Data Cleaning & Preparation

## Project Overview

This project was completed as part of Task 1 of my internship with SWYNEX Technologies.

The objective of this task was to clean and prepare the Global Superstore dataset for further analysis.

## Dataset

The Global Superstore dataset contains information related to:

- Orders
- Customers
- Products
- Sales
- Profit
- Quantity
- Shipping
- Regions and Markets

## Tools Used

- Microsoft Excel
- Python
- Pandas

## Data Cleaning Performed

The following data quality checks and cleaning activities were performed:

1. Checked missing values.
2. Checked duplicate records.
3. Checked incorrect data types.
4. Standardized date formats.
5. Removed unnecessary spaces from text values.
6. Checked inconsistent categorical values.
7. Checked numerical columns for invalid values.
8. Validated the final cleaned dataset.

## Files Included

### Dataset

- `Global_Superstore_Raw.csv` - Original dataset before cleaning.
- `Global_Superstore_Cleaned.csv` - Final cleaned dataset.

### Excel

- `Global_Superstore_Raw.xlsx` - Original dataset in Excel format.
- `Global_Superstore_Cleaned.xlsx` - Cleaned dataset in Excel format.

### Python

- `data_cleaning.py` - Python script used for data cleaning and validation.

## Result

The dataset was cleaned and prepared for further analysis and visualization.

## Learning Outcome

Through this task, I practiced data cleaning, data quality checks, handling missing values, identifying duplicates, standardizing data and preparing datasets for analysis using Excel and Python.
